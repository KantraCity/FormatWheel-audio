# Format Wheel — расширение «Аудио»

Конвертация и простая обработка аудио для [Format Wheel](https://github.com/KantraCity/FormatWheel). FFmpeg не нужен: работает на встроенных кодеках Windows (Media Foundation) через [NAudio](https://github.com/naudio/NAudio).

- **Вход:** MP3, WAV, FLAC, M4A, M4B, AAC, WMA, AIFF/AIFC, OGG (Vorbis и Opus), OPUS, MP2.
- **Shift — формат:** MP3, M4A (AAC), OPUS, FLAC, ALAC, WMA, WAV, AIFF. Без выбора всё уходит в MP3, а сам MP3 — в M4A.
- **Ctrl+Shift — битрейт:** 192k (по умолчанию), 320k, 256k, 128k, 64k. Для M4A кодек Windows умеет максимум 192k, Opus берёт половину выбранного — ему этого хватает. На FLAC, ALAC, WAV и AIFF битрейт не влияет.
- **Alt+Shift — каналы:** как есть, моно, стерео. Многоканальный звук (5.1 и т.п.) сводится к стерео.
- **Ctrl+Alt+Shift — громкость:** как есть, «Выровнять», +6 dB, −6 dB.

Всё сочетается за один драг: например, MP3 + 64k + моно + выровнять — компактная запись голоса.

## «Выровнять»

Подтягивает громкость к **−14 LUFS** — так её выравнивают YouTube и Spotify. Громкость меряется «на слух» по стандарту ITU-R BS.1770, а не по пику: у большинства записей пик и так у 0 dB, а звучат они тихо. После усиления работает лимитер, пики не поднимаются выше −1 dB, поэтому хрипа нет. Усиление ограничено ±24 dB, чтобы не раздувать шум в почти пустых записях.

## Совместно с расширением FFmpeg

У расширения FFmpeg тоже есть аудио. Колесо отдаёт файл первому расширению, которое его берёт, а папки расширений перебираются по алфавиту. Поэтому `audio` идёт раньше `ffmpeg` и аудиофайлы достанутся этому расширению, а видео по-прежнему FFmpeg. AC3, DTS, APE и прочие редкие форматы это расширение не берёт, их конвертирует FFmpeg. Если нужен OGG Vorbis на выходе — удалите это расширение, и всё аудио снова уйдёт в FFmpeg.

## Установка

1. Сначала поставьте саму программу Format Wheel.
2. Запустите `FormatWheel-Audio-Setup-x.y.z.exe` из релизов.
3. В Format Wheel откройте меню трея → «Расширения» → «Перезагрузить расширения» (или перезапустите программу).

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```
